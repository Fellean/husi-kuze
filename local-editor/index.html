Jednou nastavit, potom jen klikat

Editor → GitHub → Cloudflare → web

Tlačítko „Uložit a publikovat“ zapíše obsah do projektu, vytvoří Git commit a odešle jej do repozitáře. Cloudflare sleduje GitHub a po každé změně sestaví novou verzi webu.

01

První přihlášení

V počítači musí být Git a přihlášení k GitHubu. Nejsnazší je jednou otevřít repozitář v GitHub Desktopu.

02

Úprava

Spusť START_EDITOR.bat, klikni do textu, přidej obrázek nebo přesuň kartu.

03

Publikace

Růžové tlačítko udělá commit a push. Heslo ani token editor nezná; použije bezpečné přihlášení Gitu v počítači.

04

Nasazení

Cloudflare automaticky sestaví větev nastavenou jako Production branch. Pro ostrý web to má být main.
